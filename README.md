# CollMan Web

Open the app: https://antoninofulci.github.io/CollMan-web/

This repository contains only the compiled web application and its GitHub Pages
deployment workflow. Application source and development history are maintained
in a separate private repository. Successful verified builds update `site/`
automatically. Do not edit generated files directly.

Local browser data is separate from desktop installations. Keep exported backups;
clearing site storage can remove local data. Account sync is available for
supported collection data. The initial catalog download is approximately 53 MB.
